# ICN Runway Live 3.0

인천공항 항공기 관측·활주로 예측·개인 스포팅 일정 PWA.

## 기능
- ADSB.lol 공개 위치 데이터, 비동기 갱신·요청 중복 방지·오류 재시도.
- 8개 활주로 방향의 최종 접근 후보 및 예상 도착시간. 평행 활주로가 모호하면 복수 후보를 표시합니다.
- 3회 이상 위치 변화와 20초 이상의 연속 접근, 하강, 중심선과 진행방향 일치를 확인해야 높은 신뢰도를 표시합니다. 신뢰도는 검증된 확률이 아닙니다.
- 복행/상승, 지상, 오래된 위치, 지나치게 높은 접근각은 착륙 예측에서 제외합니다.
- 도착은 속도 유지 가정의 예상시간순, 출발 상승은 최초 관측시각순. 미래 이륙 관제 순서는 예측하지 않습니다.
- 특별편 관심 기종·등록번호·호출부호 필터. 화물기라는 이유만으로 특별편으로 분류하지 않습니다.
- 특별편 일정 직접 등록·수정·삭제, 한국시간순 정렬, JSON 내보내기/가져오기. 데이터는 사용한 브라우저의 로컬 저장소에만 보관됩니다.

## 일정 관련 제한
공식 항공사/공항 운항스케줄 API는 아직 연결되지 않았습니다. 특별편 자동 탐지·미래 운항일정 자동 수집·장기 방문빈도 분석은 제공하지 않습니다. 공식 인천공항 운항현황 API 사용에는 공공데이터포털 활용신청과 인증키가 필요합니다. 키는 브라우저나 GitHub에 올리지 말고 서버 비밀 환경변수로 연결해야 합니다.
ADS-B 호출부호와 항공사 판매 편명은 다를 수 있어 등록번호 또는 명시적으로 등록한 호출부호가 일치할 때 연계합니다. 직접 등록 일정은 항상 별도로 표시합니다.

## 실행 및 배포
Python 표준 라이브러리만 사용합니다.

```sh
python -m unittest test_tracker.py
python -u server.py
```

Render free / Singapore. Build: `python -m unittest test_tracker.py`. Start: `python -u server.py`. `HOST=0.0.0.0`, `PORT`는 Render 제공값을 사용합니다.

무료 인스턴스는 유휴 상태에서 중지될 수 있습니다. 메모리 관측 이력은 서버 재시작 시 초기화됩니다. API 가용성과 수신 범위에 따라 항공기 표시가 제한될 수 있습니다. 실제 관제 배정, 확정 착륙, 활주로 폐쇄 안내용이 아닙니다.

데이터: [ADSB.lol](https://www.adsb.lol/) (ODbL 1.0). 지도는 좌표 도식이며 실제 지형을 표시하지 않습니다.
